# packages/brand

The single copy of the ConverseKit brand assets. Not an npm workspace —
nothing imports it as a package. It is a directory that three build
steps copy out of:

| Consumer | How it gets here |
|---|---|
| `apps/site` | `scripts/build-assets.mjs` copies `assets/brand/` and `assets/fonts/` into `apps/site/dist/` |
| `apps/cdn` | same script; `assets/fonts/` is copied once per widget version prefix, because the widget derives its asset base from its own `<script src>` |
| `apps/app` | Vite `publicDir` in `apps/app/vite.config.ts` points at `assets/` |

Copied rather than referenced cross-origin on purpose: the landing page
and the dashboard then keep same-origin favicon and font loads, and
neither one is down because `cdn.` is.

- `assets/brand/` — favicons, logos, the OG image and the web manifest.
  Regenerated by `node scripts/gen-brand-assets.mjs`, which needs
  `@resvg/resvg-js` and the three TTFs named at the top of that file.
  Hand edits will be overwritten.
- `assets/fonts/` — vendored woff2 subsets. See [FONTS.md](FONTS.md) for
  provenance and the subsetting command.

Everything under `assets/` is copied verbatim by all three consumers, so
nothing that is not meant to be served belongs in it — which is why
these notes sit one level up.
